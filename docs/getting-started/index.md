# Your first week with Ledgerly

Ledgerly helps you answer four practical questions: where money went, what an ordinary month costs, how much room remains for goals and investing, and what would change under a different plan. It uses statement imports, not a live bank connection.

## 1. Install and create the first household

Follow [macOS](../installation/macos.md) or [Windows](../installation/windows.md), then complete [first setup](setup.md). A **login user** signs in; a **financial member** represents someone whose finances you model. A member does not need a login. Set up all financial members before importing so ownership choices are useful.

## 2. Bring in the main current account

Export original CSV transactions from your bank. Open **Import Statements**, choose a file and select **Analyse & import**. Start with several months where possible. Ledgerly detects supported layouts or asks you to map columns. Review the account and owner carefully, especially when using more than one account at the same bank. [Import guide](../guide/imports.md).

## 3. Add other accounts and cards

Import both sides of regular transfers and card repayments where available. Multiple account records are supported, but native bank formats do not reliably distinguish every same-bank account. Check [account limitations](../guide/imports.md#multiple-accounts-and-remembered-formats) before bulk importing.

## 4. Review and reconcile

In **Review**, categorise unfamiliar merchant families. In **Transactions**, inspect exceptional purchases and mark genuine one-offs. In **Reconciliation**, check suggested transfers and settlements. These steps improve the spending estimates used later.

## 5. Approve real recurring commitments

Use **Recurring** to approve regular bills and identify saving/investment separately. Do not approve every grocery or fuel purchase as a fixed bill; variable essentials are estimated from history.

## 6. Set the Household Plan

Enter expected income for each financial member, inspect fixed and variable essentials, choose the lifestyle history window and decide how shared commitments are attributed. A historical estimate is a starting point, not proof that future spending will match it.

## 7. Add goals, allocate and test

Create a **Funded Goal** for an additional monthly reserve, or a **Tracking Goal** to monitor progress without another deduction. Use **Allocate** for a lifestyle allowance and additional investing, then **Forecast** to test changes before altering Plan.

## 8. Check Overview and record Wealth

Overview combines actual transactions and the current forward plan. Wealth is manual: enter dated asset/liability values when useful. It is separate from imported account flows.

You can explore the full workflow using [Demo Mode](../guide/demo.md) before entering your own records. For definitions, use the [glossary](../planning/glossary.md); for unexpected results, start with [troubleshooting](../troubleshooting.md).
