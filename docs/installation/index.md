# Install Ledgerly

Use the installer for the computer that will run Ledgerly and store its financial records. The documentation website is a guide and download service; it is not your installed financial application.

| Platform | Start here | Normal browser endpoint |
|---|---|---|
| macOS 13+ declared minimum | [macOS guide](macos.md) | `https://localhost` on the installed Mac, port 443 |
| Windows 11 x64 / ARM64 | [Windows guide](windows.md) | Installer-created Start Menu shortcut using the installation LAN IP; local HTTPS is also configured |

[Verified installers and checksums](../downloads.md) · [Upgrading without losing data](upgrading.md)

Initial setup downloads dependencies, so keep internet access available and allow normal administrator prompts. Once installed, the financial application and bundled charts do not depend on the public documentation website to run.

Do not install a second empty data store or delete a database to bypass an error. Read [safe troubleshooting](../troubleshooting.md) first. Existing installations should use the normal newer installer/launcher so its upgrade path can preserve data.
