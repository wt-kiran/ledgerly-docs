Start with [your first week](../getting-started/index.md), then use the [monthly routine](../getting-started/routine.md). For a connected explanation of headroom, read [how the financial plan fits together](../planning/index.md).

!!! warning "Early-release access controls"
    Viewer is not an enforced read-only role. Startup also has a primary-household membership limitation. Treat login users as trusted people; household separation is not a security boundary against an untrusted user. See [permissions](households.md#roles-and-actual-permissions).
