# Local Help and About

Use the **?** button at the top of a financial screen to open the installed Help portal. The local guide provides page explanations and field guidance without needing the public documentation website. Its menu links to other help topics. There is no local Help search field; this website's full-text search is separate.

Choose **About Ledgerly** in the sidebar to check the installed application version, Warwick Technologies Ltd ownership, proprietary licence notice, financial-information notice and support email. About is read-only; there are no editable fields or Save action.

## When to use them

If you are unsure what a field means, open local Help first. If reporting an issue, note the version shown in About and your platform. The public website describes v3.8.5; an older installed version can differ.

The application remains proprietary software. The documentation repository is not a licence to redistribute private application source, financial databases or installer-builder archives. Obtain the app from the [verified downloads page](../downloads.md).

**Example:** a Goals page screenshot and About v3.8.5 help support identify a provision-versus-savings question without sending your database. Use fictional Demo data where possible.
