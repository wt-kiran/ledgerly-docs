# Demo Mode and navigation

Choose **Continue with Demo** on the login page to explore fictional data without normal household credentials. Demo uses its own household database; it does not display real household finances. It is editable, not a read-only tour.

## Explore safely

1. Enter Demo from login and confirm **DEMO DATA** in the sidebar.
2. Follow Overview → Transactions → Reconciliation → Recurring → Plan.
3. Open Goals to compare Funded and Tracking behaviour, then Allocate and Forecast.
4. Use **Reset demo data** to rebuild the original fictional dataset when finished experimenting.
5. Select **Leave demo** to return to login. This clears the Demo session, not your real households.

The initial v3.8.5 seed includes an **Annual activities** Funded Goal with £100/month provision and an **Emergency fund** Tracking Goal. Editing or resetting Demo changes the values you see. Some screenshots show a deliberately edited £1,000/month fictional Car goal instead; it is an example, not a default for your own household.

## Shared navigation

The sidebar provides the financial screens and installed version. Real sessions can show a household selector and sign-out action; Demo shows Reset/Leave instead and does not allow real household administration. The question-mark control opens local Help for the current screen in a separate tab. About displays ownership, support and installed version.

The household switcher is available when multiple permitted real households exist. Its only visible setting is which household is active; the page/security identifiers submitted behind the scenes are not user settings.

## Example and limits

Pause the fictional £100 Funded Goal: current raw headroom rises by £100, while its Already saved value does not change. Reactivate it to restore the reserve. A Tracking contribution can change its savings forecast without another headroom deduction.

Demo is separate from real financial records, but there is no per-visitor disposable Demo session or automatic reset when leaving. Other people using the same local installation can see the edited Demo until it is reset. Do not import real CSVs into Demo for a public screenshot or demonstration.
