# Ledgerly's numbers and terms

| Term | Meaning |
|---|---|
| Login user | A local sign-in account, separate from financial-member records |
| Financial member | A person whose finances are modelled inside a household |
| Account owner | Financial member associated with a bank/card account; not necessarily the person economically responsible for every cost |
| Responsibility | Household or member assigned to a planned commitment |
| Income | Positive credits classified as income, rather than transfers |
| True / net spending | Net expense amounts, excluding transfer/investment category movements; expense refunds reduce it |
| Cash surplus | Actual income minus net expense spending; not necessarily the bank-balance change |
| Imported flow | Sum of imported transactions; not a verified current/opening account balance |
| Fixed commitment | Approved recurring bill included in Plan at a monthly equivalent |
| Variable essential | Necessary expense category estimated from history or overridden in Plan |
| Cash allocation | Existing planned cash-pot reservation; the bank movement itself may be an internal transfer |
| Monthly provision | Funded Goal planning commitment; not a transaction or automatic saving |
| Already saved | Manually recorded actual goal progress |
| Monthly savings contribution | Assumption driving a goal's progress forecast, separate from provision |
| Raw headroom / capacity | Expected income less core costs, Plan saving/allocations and additional active Funded provision, before lifestyle |
| Historical lifestyle | Sum of relevant category medians over the selected history window |
| After-lifestyle position | Raw headroom less selected historical lifestyle; Plan/Allocate can separately show deliberate allowance comparisons |
| Safety buffer | Capacity left after Allocate's lifestyle allowance and extra investing; funded provision is already in raw headroom |
| One-off | Remains actual spending but excluded from normal planning history |
| Scenario | Saved assumptions that do not change real transactions or Plan |
| Net worth | Latest manual asset values less latest manual liabilities |
