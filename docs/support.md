# Support and bug reports

Contact [help@getledgerly.co.uk](mailto:help@getledgerly.co.uk). Ledgerly is developed by Warwick Technologies Ltd.

## Include useful, safe information

- Installed version from About Ledgerly, platform/architecture and whether this was a fresh install or upgrade.
- The screen/action, what you expected and what happened instead.
- Exact error text and a short redacted log excerpt if relevant.
- Whether it reproduces with fictional Demo data and a screenshot of that example if possible.
- For downloads, the asset name and checksum mismatch if that is the problem.

Do not send passwords, the signing secret, live databases, backup archives or unredacted statement CSVs by default. Remove names, account numbers, balances, property details, sensitive paths and transaction descriptions from screenshots/logs. File names themselves can contain private information.

For an unfamiliar CSV, describe column headings and the bank/export type first. If a sample is needed, prepare fictional rows that preserve only the structure after agreeing a safe support process. Do not upload real financial data to the public documentation repository.

Before reporting a number, use the [monthly checks](getting-started/routine.md). Before reinstalling, read [safe troubleshooting](troubleshooting.md) and [backups](backups.md). Do not try destructive database commands merely because a result seems surprising.
