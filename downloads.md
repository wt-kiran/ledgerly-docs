# Download Ledgerly

**Current version: 3.8.5**

Ledgerly is currently available for macOS and Windows as part of an early testing release.

## macOS

Download the latest macOS installer (DMG) from the release page below.

After downloading, open the DMG and follow the installation instructions.

## Windows

Download the latest Windows installer (EXE) from the same release page.

The installer supports Windows x64 and ARM64.

## Get the latest version

[Download Ledgerly 3.8.5](https://github.com/wt-kiran/ledgerly-docs/releases/latest)

## Important information

Ledgerly is early-release software. Keep a backup of important financial records and do not rely on its calculations as a substitute for professional financial or tax advice.

Your Ledgerly financial database is stored locally on your computer.
